PIXEL : apprendre le JavaScript en jouant

Dans PIXEL, tu programmes un pixel rouge pour traverser des niveaux en 3D. Le terminal te permet de donner des commandes et d’écrire tes propres fonctions, sans installer de logiciel.

Les notions de code à découvrir

  • Écrire et appeler des fonctions JavaScript pour réutiliser une suite d’actions.
  • Utiliser des boucles pour répéter des commandes et planifier un déplacement.
  • Lire un objectif, observer le plateau et décomposer un problème en étapes.

Comment jouer à PIXEL ?

Saisis les commandes dans le terminal à droite ou crée une fonction dans le panneau dédié, puis exécute ton programme. Les six niveaux proposent des objectifs progressifs autour du déplacement, des cubes, des portes et du tir. Tape help() dans le terminal pour découvrir les commandes disponibles.

Questions fréquentes

Faut-il déjà savoir coder ?

Non. PIXEL est une initiation : les commandes et l’aide intégrée permettent de commencer pas à pas.

PIXEL est-il gratuit ?

Oui, le jeu est accessible gratuitement directement dans le navigateur.
