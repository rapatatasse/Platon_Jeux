Le jeu

Tu pilotes un pixel rouge uniquement avec du code JavaScript, tapé dans le terminal ou écrit dans le panneau « Mes fonctions ». Chaque niveau a un objectif (traverser une porte bleue, ramasser des cubes, détruire des violets, former une figure...).

  • Jaune : un cube ramassé se pose sur le rouge. Il fait grandir ton corps et augmente la portée du scanner.
  • Violet : danger. Si le rouge en touche un, c'est perdu. Un violet se détruit à la balle ou par écrasement.
  • Blanc : mur incassable. Bleu : porte, le rouge doit marcher dessus.
  • Les cubes ne flottent jamais : ils retombent. Un cube jaune qui n'est plus relié au rouge disparaît.
  • Un violet détruit te rend une balle.
  • Axes : X = gauche (-) / droite (+), Z = haut (-) / bas (+) de l'écran, Y = hauteur (0 = sol).

Le monde avance d'un « pas » (tick) toutes les 500 ms et exécute une commande par pas.

Commandes

CodeEffet
move(1, 0)Avance d'une case : move(x, z) avec x et z valant -1, 0 ou 1 (diagonales permises, 1 pas). C'est la seule commande de déplacement.
fire(1, 0, 0)Tire une balle dans la direction [x, y, z]. Elle détruit le premier pixel touché (pas les murs).
moveYellow(0, [1, 0, 0], 1, [1, 1, 0])Place le cube 0 en (1, 0, 0) et le cube 1 en (1, 1, 0), relativement au rouge.
wait(3)Ne rien faire pendant 3 pas.
stop()Vide la file des commandes en attente (bouton STOP).
console.log(...)Affiche une valeur dans le terminal.

Le scanner

La variable Scanner liste les violets, les jaunes et les murs ("mur") proches. La zone scannée est le carré de côté 2 × portée + 1 autour du rouge. La portée vaut 1, plus 1 par cube jaune empilé directement au-dessus du rouge.

Scanner
[
  { "type": "violet", "coordinates": [[0, 1], [1, -1]] },
  { "type": "jaune",  "coordinates": [[3, 0]] }
]

Chaque coordonnée est [dx, dz] : le décalage par rapport à toi. Ici, deux violets sont juste à côté et un jaune est 3 cases à droite (visible parce que la portée est d'au moins 3). Un type absent de la liste n'existe pas dans la zone.

Attention : les murs ne sont pas listés, et la cible peut sortir de la zone si tu fais un détour. Retiens-la dans une variable.

const jaunes = Scanner.find((e) => e.type === "jaune");
if (jaunes) console.log("premier jaune :", jaunes.coordinates[0]);

Réagir à ce qui se passe : async / await

Une fonction normale pose toutes ses commandes d'un coup dans la file, avant qu'elles soient jouées : Scanner ne change pas pendant la fonction. Pour réagir (par exemple changer de direction quand le pixel est bloqué), écris une fonction async et mets await devant la commande : on attend que le pas soit joué.

  while (!Gates[0].passed) {
    //Action
    }
  }
}

Un pas bloqué (mur) est quand même un pas dépensé.

Mode test des niveaux

Le bouton Niveaux ouvre la liste des niveaux. Choisis une de tes fonctions (sans argument) et lance les tests : le jeu la joue seule, sans toi, sur le niveau et sur ses variantes (porte déplacée, couloir inversé, moins de balles...). Ta fonction doit donc marcher quelle que soit la disposition : lis les variables au lieu d'écrire des nombres en dur.

Certains tests limitent le nombre de pas (chemin le plus court, diagonales comprises, multiplié par un budget). Les tests réussis sont mémorisés dans ton navigateur et affichés par niveau.

Bibliothèque JavaScript : les bases

Variables

const nom = "pixel";     // ne change jamais
let compteur = 0;        // peut changer
compteur = compteur + 1; // ou compteur++

Types courants : nombre (3), texte ("abc"), booléen (true / false), tableau ([1, 2]), objet ({ x: 1, z: 2 }).

Opérateurs

+ - * /          // calcul
%                // reste de la division (7 % 2 vaut 1)
=== !==          // égal / différent (toujours trois signes)
< > <= >=      // comparaisons
&& || !          // et / ou / non
Math.abs(-3)     // 3     Math.sign(-8) // -1 (0 si 0)
Math.max(2, 5)   // 5     Math.min(2, 5) // 2

Conditions

if (BulletsCount > 0) {
  fire(1, 0, 0);
} else if (Gates[0].x < 0) {
  move(1, 0);
} else {
  wait(1);
}

Boucles

for (let i = 0; i < 5; i++) move(1, 0);   // répéter 5 fois
while (condition) { /* tant que c'est vrai */ }
for (const c of CubesOffsets) console.log(c.y);   // parcourir une liste

Évite les boucles sans fin : la file de commandes est limitée et le bouton STOP la vide.

Fonctions

function avance(n) {
  for (let i = 0; i < n; i++) move(1, 0);
}
avance(3);

function double(x) { return x * 2; }   // return renvoie un résultat

Tableaux

const liste = [10, 20, 30];
liste[0]            // 10 (on compte à partir de 0)
liste.length        // 3
liste.push(40)      // ajoute à la fin
liste.find((n) => n > 15)           // 20 : premier élément qui convient
liste.filter((n) => n > 15)         // [20, 30, 40]
liste.map((n) => n * 2)             // [20, 40, 60, 80]
liste.forEach((n, i) => console.log(i, n))

Objets

const p = { x: 3, z: -2 };
p.x            // 3
p.z = 5;       // modifier
const { x, z } = p;   // sortir x et z de l'objet

Texte

"x=" + 3             // "x=3"
`x vaut ${p.x}`      // texte avec valeurs insérées

Async / await

Une fonction async peut await une commande : voir la section ci-dessus.

Erreurs fréquentes

  • Séparer par des virgules, pas des points-virgules : move(1, 0), et toujours avec des parenthèses.
  • = affecte, === compare.
  • Les listes commencent à 0.
  • Lire le message en rouge dans le terminal : il dit presque toujours quoi corriger.
